# DONEX 🤝♻️

O **DONEX** é um aplicativo Android focado em economia circular e solidariedade. Desenvolvido para facilitar a doação e troca de itens, o app conecta pessoas que possuem objetos parados a quem realmente precisa deles, utilizando geolocalização e chat em tempo real.

## ✨ Funcionalidades

* **Feed de Postagens:** Explore as ofertas de doação em uma interface moderna e intuitiva.
* **Chat em Tempo Real:** Converse diretamente com o doador para combinar a entrega (Powered by Firebase Firestore).
* **Perfil Personalizado:** Gerencie sua bio e suas postagens ativas.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** [Kotlin](https://kotlinlang.org/)
* **UI:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Design Declarativo)
* **Backend:** [Firebase](https://firebase.google.com/)
    * *Firestore:* Banco de dados NoSQL para posts e mensagens.
    * *Auth:* Autenticação segura de usuários.
* **Arquitetura:** MVVM (Model-View-ViewModel).
* **APIs:** Google Maps SDK para Android.

## 🚀 Como rodar o projeto

1. Faça o clone do repositório.
2. Adicione o seu arquivo `google-services.json` na pasta `app/`.
3. Sincronize o Gradle e rode no seu emulador ou dispositivo físico.
